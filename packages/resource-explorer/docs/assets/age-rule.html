The age rule, at all three levels

Three channels that cannot collide: glyph says which state, hue says whether a person is needed, rule says how old. Age grades rather than flags, and never recolours — “this answer is old” and “this answer is bad” are different claims.

Column 1 and 3 are the point: a run of thirty-day cells reads as a broken underline down the grid, visible without inspecting any single cell. That only works because the rule spans the whole 26px cell and adjacent rules meet.

Two defects this rendering found, neither visible in code review:

  • Drawn on the button while the cell carried the padding, the button measured 14px inside a 26px cell — “full cell width” was 54% of the cell, and adjacent rules never met.
  • Moved to the <td> instead, the rule computed 1700px wide: a position: relative table cell did not establish the containing block, so width: 100% resolved against the table.

Levels: none under 7 days · 40% hairline past 7 · full width past 30. 7 and 30 are placeholders — calendar habits, not facts about surveys. The honest measure is “older than this analysis's own re-run cadence”, which Automate will own.
