# Resource Explorer design-notes timeline

This file is a short, blog-usable history of how Resource Explorer's design and build decisions unfolded, one entry per note in this folder, oldest first. It is kept as a historical record: entries stay here even after the notes themselves are later consolidated or moved. The coordinator session is the single writer of this file, and adds an entry when a note merges. The date is the date of the commit that introduced the note to the repository, which can be later than the date written inside the note (several designer notes landed in one bulk commit on 2026-09-16). The `[unchecked]` tag means the sentence was generated from the note's title and opening paragraph and has not been confirmed against the whole note; entries without the tag were read for their decision or outcome.

Entry format: `date | title | what was decided or built | note file | introducing commit`.
